I walked through AdaL — an AI coding agent by SylphAI — as a brand-new developer, 15-minute budget, zero prior knowledge. Below is every finding, exactly as delivered.
Methodology
Fresh-user walkthrough · Google → landing → docs → install → first run · No briefing · 15-min budget · Karachi, Pakistan · April 2026
Critical
Free trial completely invisible on landing page
Page shows only paid plans — $20, $100, $200/month. The 7-day free trial exists but appears nowhere on the landing page, quickstart, or pricing section. First-time visitors see only paid options and bounce.
→ Fix: 1 line of copy above pricing. Highest conversion impact on the site.
Critical
sylph.ai/docs returns a 404 page
The intuitive URL for docs returns "Oops! Page not found." Docs live at docs.sylph.ai — but anyone who guesses the URL, follows an old link, or clicks a search result hits a dead end. Dead URLs kill trust immediately.
→ Fix: One nginx redirect. ~30 min engineering time.
Critical
Three different install commands across three channels
Landing page: nothing. Quickstart: curl. LinkedIn: npm. A developer following recent social posts uses the wrong command, hits an error, and has zero guidance. First impression = broken product.
→ Fix: Standardize one command. Update LinkedIn posts.
Critical
Careers page invisible to search engines
SPA-rendered — bots see only a shell HTML file. A hiring post with 167 reactions sends traffic to a page Google cannot read. Job listings are completely invisible to developers searching for roles.
→ Fix: SSR or static HTML fallback.
Medium
Hero text doesn't say what AdaL is
"Bringing ideas to life for developers worldwide" — can't tell if this is an IDE, CLI, library, or SaaS. The killer feature (mid-session model switching) is buried below the fold.
→ One-liner: "AI coding agent that switches models mid-session."
Medium
No expected terminal output in quickstart
After running adal, docs say "First run opens browser for auth" — but show nothing of what success looks like. Developers can't confirm they succeeded or diagnose failure.
→ Add one terminal output screenshot.
Medium
No troubleshooting section anywhere
What if install fails? Auth browser won't open? No guidance exists for any first-run failure. These exact failures kill activation and are easily fixed with one doc page.
→ Add: PATH, Node version, auth timeout, firewall.
Good
Quickstart structure is solid once you reach it
3 clear steps (Install → Launch → Try It), copy-paste commands, shortcuts table. One of the strongest pages in the product. The problem is the journey to it — not the page itself.
→ Keep this. Build on it.
